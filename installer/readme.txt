ROCKETIFY - READ ME

What this installs
  - Rocketify.exe in Rocket League\Binaries\Win64
  - The mod loader in Binaries\Win64\rocketify
  - A mods folder: Binaries\Win64\rocketify\mods (put mod .dll files here)

How it works
  Rocketify starts the game together with the mod loader. A MODS
  entry appears in the main menu. Mods in the mods folder are loaded at start.

Important - Easy Anti-Cheat
  The modded game runs WITHOUT Easy Anti-Cheat. Use it for offline modes
  (freeplay, training, workshop maps, local matches).
  To play online, start Rocket League normally (Steam / Epic Play button with
  no launch options). Your normal game is not changed by this installer.
  The mod loader switches itself off if Easy Anti-Cheat is ever present.
